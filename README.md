# ЛОТО-КВИЗ онлайн

Многопользовательский прототип на Node.js + Express + Socket.IO. Ведущий создаёт комнату, получает код и QR-ссылку; участники входят с телефонов; ответы и таблица очков синхронизируются в реальном времени. Аудиофайлы загружаются на сервер, музыку запускает ведущий.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте http://localhost:3000. Для проверки с телефона в той же Wi-Fi сети используйте локальный IP компьютера вместо localhost.

## Публикация в интернете

Разверните проект на хостинге, который поддерживает Node.js и WebSocket (например, Render, Railway или VPS). Укажите команду запуска `npm start`, Node 18+. Для сохранения загруженных аудиофайлов между перезапусками нужен постоянный диск или внешнее объектное хранилище. На бесплатных эфемерных дисках файлы могут исчезать.

QR-код формируется из публичного URL сайта. Поэтому после публикации он будет вести на реальный адрес приложения.

## Важно для production

Это стартовый прототип: комнаты хранятся в памяти процесса, при перезапуске сервера сбрасываются; нет авторизации ведущего, защиты от злоупотреблений, постоянной базы данных и автоматической проверки правильности ответа. В текущем MVP ведущий вручную начисляет очки кнопкой +1. Для публичного запуска следует добавить базу данных, защищённый токен ведущего, лимиты загрузки, модерацию ответов и постоянное хранилище файлов.
